# oaleviola

README do perfil do Alexandre Viola no GitHub, a página pública que abre em github.com/oaleviola.

**Este arquivo existe só para apontar para o Arroway.** Tudo o que se sabe e se decidiu sobre este repositório, inclusive onde fica cada peça da infraestrutura, está no Arroway, no projeto `ale`.

- Antes de agir: `arroway_read` no projeto `ale`, com o contexto da tarefa, e use o que ele devolver.
- Para dizer onde as coisas estão: `arroway_catch_up`.
- Antes de recomendar: `arroway_norms`.
- Ao terminar: `arroway_log` com o que o trabalho resolveu. Parou no meio: `arroway_pass`.

Decisões e constatações vão para o Arroway, nunca para arquivo deste repositório. Quando um arquivo daqui diz o contrário do Arroway, vale o Arroway.

O que o código faz hoje está em `README.md`.
